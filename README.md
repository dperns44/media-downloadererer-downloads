## Windows

Download the Setup EXE above and run it. The installer includes the media tools and adds a desktop shortcut. This beta is unsigned; Windows or company policies may require approval. [Release details and checksums](releases/tag/v1.8.0-beta.4).

## Lite trial

Open Lite, paste a public video link, click **Get video**, then choose **Download video** or **Cut & export**. Mac and Windows users can open the website; Chrome is the tested browser. Safari has not been tested.

Lite currently limits links to 20-minute videos and 200 MB outputs. Some sites require login or block downloads. The host PC must stay awake and connected; when it is offline, link downloads are unavailable. Browser editing of local files remains available. Temporary server downloads expire after one hour while the service is running.
